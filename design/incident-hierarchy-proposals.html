Design exploration — not production code

Incident page hierarchy

Same colours, tier styling, dark theme, content and copy as the current page. Only hierarchy, layout, typography, spacing, grouping and states are being explored — nothing here changes what the page says, only how fast a tired manager can read it at 3am.

Reading order the page should support: how serious & is it done → what happened → the key facts → proof → who said what.

A — current layout, recreated faithfully B / C — proposals, structurally different from each other
